# AI Emotion Recognition System

A real-time AI based facial emotion recognition application using Python.

## Technologies Used
- Python
- OpenCV
- DeepFace
- PySide6
- SQLite

## Features
- Live camera emotion detection
- Facial emotion analysis using DeepFace
- PySide6 dashboard interface
- Emotion history database storage

## How to Run

Install requirements:

pip install -r requirements.txt

Run application:

python login.py
